# 💻 Notch For Windows
Trasforma il tuo spazio di lavoro con un notch intelligente e multifunzione.

Notch-For-Windows è un'applicazione esterna progettata per integrare un'area interattiva nella parte superiore dello schermo, portando funzionalità rapide e informazioni utili a portata di click, senza ingombrare la barra delle applicazioni.

## 🚀 Funzionalità Principali
Il notch non è solo estetico; è progettato per migliorare la produttività. Ecco cosa può fare:

Monitoraggio di Sistema: Visualizza in tempo reale l'uso della CPU, RAM e lo stato della batteria.

Media Control: Gestisci la riproduzione musicale (Play/Pause, Skip) direttamente dal notch.

Quick Actions: Accesso rapido a scorciatoie di sistema come screenshot, blocco schermo o spegnimento.

Notifiche Intelligenti: Visualizzazione discreta delle notifiche in arrivo.

Personalizzazione: Cambia colori, dimensioni e comportamento del notch per adattarlo al tuo wallpaper o tema (Light/Dark mode).

## 🛠 Installazione
Scarica l'ultima release dalla sezione Releases.

Estrai il file .zip.

Avvia l'eseguibile NotchForWindows.exe.

Opzionale: Aggiungi il programma all'avvio automatico di Windows nelle impostazioni dell'app.
