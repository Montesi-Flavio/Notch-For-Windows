# Contribuire a Notch For Windows 🚀

Prima di tutto, grazie per aver dedicato del tempo a contribuire! Questo progetto è open-source e ogni aiuto (che sia una correzione di bug, una nuova feature o un suggerimento) è ben accetto.

## Come posso contribuire?

### 1. Segnalare Bug 🐛

Se trovi un problema tecnico, per favore apri una [Issue](https://github.com/Montesi-Flavio/Notch-For-Windows/issues) includendo:

- Una descrizione chiara del bug.
- I passaggi per riprodurlo.
- La tua versione di Windows.

### 2. Suggerire Nuove Funzionalità ✨

Hai un'idea per un nuovo widget nel notch? Apri una Issue etichettandola come "enhancement" e descrivi come dovrebbe funzionare.

### 3. Inviare una Pull Request (PR) 🛠️

Se vuoi scrivere del codice:

1. Fai il **Fork** del progetto.
2. Crea un branch per la tua modifica: `git checkout -b feature/NomeNuovaFeature`.
3. Fai il commit dei tuoi cambiamenti: `git commit -m 'Aggiunta feature X'`.
4. Carica il branch sul tuo fork: `git push origin feature/NomeNuovaFeature`.
5. Apri una **Pull Request** spiegando cosa hai fatto.

## Linee Guida per il Codice 📖

- Cerca di mantenere il codice pulito e commentato.
- Se aggiungi una nuova funzione, assicurati che non impatti troppo sulle prestazioni (il notch deve restare leggero!).
- Rispetta lo stile di indentazione esistente nel progetto.

## Comportamento 🤝

Sii gentile e rispettoso nei confronti degli altri contributori. Siamo qui per costruire qualcosa di utile insieme!
